# Assets Directory

This directory contains static assets for the portfolio website.

## Required Files

### CV/Resume
- **Path**: `/public/Atem-Diana-CV.pdf`
- **Purpose**: Your downloadable CV/resume
- **Action**: Replace with your actual CV PDF file

### Project Screenshots
- **Path**: `/public/assets/projects/`
- **Purpose**: Screenshots for your portfolio projects
- **Required files**:
  - `folioverse.jpg` - Screenshot for FolioVerse project
  - `workconnect.jpg` - Screenshot for WorkConnect-CM project
- **Action**: Add your project screenshots in the projects directory

### Open Graph Image
- **Path**: `/public/assets/og-image.jpg`
- **Purpose**: Social media sharing image (1200x630px recommended)
- **Action**: Replace with your actual OG image

### Profile Image
- **Path**: `/public/assets/profile.jpg`
- **Purpose**: Your professional profile photo
- **Action**: Add your profile image as `profile.jpg` in the `/public/assets/` directory
- **Used in**: Hero section (circular avatar) and About section (square card)

## Instructions

1. **CV**: Place your CV PDF file as `Atem-Diana-CV.pdf` in the `/public/` directory
2. **Project Images**: Add project screenshots to `/public/assets/projects/` directory
3. **OG Image**: Add a 1200x630px image for social media sharing
4. **Profile Image**: Add your professional photo as `profile.jpg` in `/public/assets/` directory

## Image Recommendations

- **Format**: JPG or PNG
- **Size**: Optimize for web (under 500KB per image)
- **Dimensions**: 
  - Project screenshots: 1200x800px or similar 3:2 ratio
  - OG image: 1200x630px
  - Profile image: 400x400px (square) or higher resolution
